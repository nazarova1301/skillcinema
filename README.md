# Мобильное тестирование :iphone:

Я протестировала мобильное приложение Skillcinema для Android, предназначенное для поиска фильмов и сериалов, а также управления коллекциями фильмов. Для тестирования я использовала как реальное устройство, так и эмулятор "Android Studio".

Пожалуйста, ознакомьтесь с результатами моей работы:
* [Тест-кейсы 1](https://docs.google.com/spreadsheets/d/1-YLHUej2zlFh7xiQnVzH4FwPYI1D0ndZMPGDZG0HCwE/edit?usp=drive_link) – UI тестирование MVP-версии приложения Skillcinema для Android.
* [Тест-кейсы 2](https://docs.google.com/spreadsheets/d/12Y2atWTZMqBEMlI2mr9-9UiIJhLhG_HbSCugTZA4xws/edit?usp=drive_link) – дымовое тестирование экранов «Онбординг» и «Главная», и проверка ключевых функций приложения.
* [Тест-кейсы 3](https://docs.google.com/spreadsheets/d/1pY9AvBt-K4m8Wn8k-RsseL_jB9RNVajKv7NB1g9fBRw/edit?usp=drive_link) – полноценное тестирование интерфейса мобильного приложения.
* [Баг-репорты](https://ru.yougile.com/board/3fdvhiq9ebe6) созданы с помощью TMS YouGile, в том числе проведено тестирование аналитики.
* [Отчёт о тестировании](https://docs.google.com/document/d/1TE62fEpmehOxbMiPtRg1xRjm0VF0IY5a42FoWPnFYyI/edit?usp=drive_link) составлен после завершения тестирования.
